# Antipatrones («estética IA genérica»)

Si el plan o la web contiene algo de esta lista **sin una razón ligada al brief**, cámbialo.

## Tipografía
- Inter, Roboto, Arial, Helvetica o `system-ui` elegidas por inercia. (Inter vale como texto neutro bajo una display muy expresiva, si se justifica.)
- Space Grotesk como «alternativa original» (Anthropic la cita como otra elección a la que el modelo converge).
- Una sola palabra del titular resaltada en otro color o en cursiva.
- Etiquetas en mayúsculas con mucho espaciado (eyebrows) encima de cada sección. Texto pequeño en mayúsculas sí vale cuando tiene contenido propio y forma parte de una composición pensada (p. ej. un póster).

## Color
- Degradado morado/violeta sobre fondo blanco.
- Crema + terracota (el nuevo cliché «cálido»). Un fondo crema sí vale si el color protagonista sale del producto del cliente.
- Casi negro + verde ácido (el nuevo cliché «tech»).
- Paletas tímidas con todos los colores al mismo peso.

## Layout y componentes
- Hero con número enorme + etiqueta pequeña + acento en degradado.
- Rejilla de tarjetas redondeadas idénticas con sombra gris (estilo SaaS).
- Maquetación de periódico con filetes finos por todas partes, sin motivo.
- Secuencia fija hero → 3 features → testimonios → CTA, sin pensar en el contenido.

## Microdetalles
- Metadatos separados por puntos medios ( · ) en cada línea.
- Etiquetas con raya (— Etiqueta).
- Flecha «→» al final de cada enlace.
- Numeración (01, 02, 03) en cosas que no son una secuencia.

## Movimiento
- Fade-in en cada elemento al hacer scroll.
- Microinteracciones dispersas sin función.

## Contenido
- Lorem ipsum, «Lorem Company», testimonios o cifras inventadas presentadas como reales.

## Proceso
- Pedir «algo bonito» o describir el gusto solo con adjetivos. El brief necesita referencias concretas.
- Copiar tal cual prompts de librerías (jiro, getlayers, motionin…): úsalos como punto de partida y adáptalos al brief, o la web acabará igual que la de todos.
